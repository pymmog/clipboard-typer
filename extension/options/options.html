Clipboard access

If you see “Could not read clipboard”:

  1. macOS Ventura+: System Settings → Privacy & Security → Pasteboard → enable Google Chrome or Safari (wording may be “Allow applications to paste to other applications”).
  2. Chrome: chrome://extensions → reload Clipboard Typer → reload the website tab.
  3. Click the toolbar icon once to type (no popup). The keyboard shortcut runs the same flow in the background.
  4. Safari: Safari → Settings → Extensions → Clipboard Typer → ensure it is allowed for the sites you use.
